2. Lyrics

Looking for the local engine

On a new computer
  1. Install Python 3.9 or newer from python.org and tick Add Python to PATH.
  2. Get the engine from the MASH-Mix repository or from its release page.
  3. Open a terminal and run pip install "mash-mix-audio-and-text[server] @ git+https://github.com/kdbn121/MASH-Mix-Audio-and-Text.git".
  4. Start it with mash-mix serve --host 127.0.0.1 --port 8000 and leave it running.
  5. Load this extension from the extension repository.

The measurements of a file need nothing of this. Only the lyrics and the voice need the engine.
