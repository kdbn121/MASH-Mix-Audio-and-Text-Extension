2. Lyrics

Looking for the local engine

On a new computer
  1. Install Python 3.9 or newer from python.org and tick Add Python to PATH.
  2. Get the engine from the MASH-Mix repository or from its release page.
  3. Open a terminal and run pip install "mash-mix-audio-and-text[server,sources] @ git+https://github.com/kdbn121/MASH-Mix-Audio-and-Text.git". The sources extra is the fetcher for links.
  4. Start it with mash-mix serve --host 127.0.0.1 --port 8000 and leave it running.
  5. Load this extension from the extension repository.

The measurements of a file need nothing of this. Only the lyrics and the voice need the engine.

The script box holds every script of every language, and it starts on "Auto, any script", which leaves the words in the script the engine heard them in. Pick a script by hand and that script is used for every language.
