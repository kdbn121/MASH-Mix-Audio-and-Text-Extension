MASH-Mix

Settings for the extension.

The address of the MASH-Mix server on this machine. Start it with mash-mix serve --host 127.0.0.1 --port 8000. The measurements of a file work without the engine, only the lyrics and the voice need it.

On a new computer

The extension measures a file on its own. The engine is only needed for the lyrics and the voice.

  1. Install Python 3.9 or newer from python.org. On Windows, tick Add Python to PATH in the installer.
  2. Get the engine from the MASH-Mix repository.
  3. Open a terminal and run
    pip install "mash-mix-audio-and-text[server] @ git+https://github.com/kdbn121/MASH-Mix-Audio-and-Text.git"
  4. Start the engine and leave it running:
    mash-mix serve --host 127.0.0.1 --port 8000
  5. Load the extension from the extension repository. Unzip it, open chrome://extensions, turn on Developer mode, press Load unpacked and pick the folder.
  6. Press Test the engine here. It answers with the version when everything is in place.

The panel also looks on the ports 8000, 8001, 8080 and 8123, so an engine on another port is usually found without changing anything.
